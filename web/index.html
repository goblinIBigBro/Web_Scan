Web-GSC

Gaussian Encoding

Realtime Control

Web-GSC is a unified Gaussian-encoding visualization and real-time rendering platform. It supports scene and manifest loading (PLY and manifest formats) with SH/SG viewers, camera capture and streamed uploads, configurable capture-to-pipeline workflows, algorithm job scheduling with runtime checks and live metrics (FPS, loss, PSNR), and shareable scene exports for easy result inspection.
